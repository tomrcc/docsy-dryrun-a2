# Docsy Starter

Welcome! This is a documentation site with a blog and a few landing pages. Everything you see on the site can be changed here.

## Quick links

- [Pages](cloudcannon:collections/pages) — the home page, About, Community and any landing pages
- [Docs](cloudcannon:collections/docs) — the documentation
- [Blog](cloudcannon:collections/blog) — news and release posts
- [Site data](cloudcannon:collections/data) — the footer, community links, and the tags and categories you can pick

## Pages

The home, About and Community pages are **landing pages**, built from blocks. Open one to see it in the Visual Editor:

- Click any heading, paragraph or button text to change it in place.
- Open **Content blocks** in the sidebar to add, reorder or remove blocks. There are five: **Cover**, **Lead**, **Features**, **Section** and **Community links**.
- To show a page in the top navigation, set **Navigation menu → Main menu → Weight**. Lower numbers come first.

Select **+ Add** to create a **Landing page** or a **Text page** (a plain page such as a privacy policy). Until you save it, a new page previews using an existing page's layout.

## Docs

Each docs page is written in the Content Editor, or edited in place in the Visual Editor. Each folder is a section with its own landing page.

- **Weight** sets a page's position in the left-hand navigation.
- **+ Add → Docs page** adds a page to the folder you're in; **+ Add → Docs section** adds a new folder.

## Blog

Posts are listed newest first by **Date**. Each post is a folder holding the post and its images, so images you upload while writing a post are saved next to it. Turn on **Draft** to keep a post off the live site while you work on it.

## Site data

- **Footer** — the copyright holder, start year and privacy policy link.
- **Links** — the icons in the footer, and the two lists on the Community page.
- **Tags** and **Categories** — the choices in the Tags and Categories fields on docs pages and blog posts. Add one here first, then pick it on a page.

## Components in docs and posts

Use the snippet button in the Content Editor's toolbar to insert:

- **Alert** — a coloured call-out box, with an optional title
- **Page info** — a status note for the top of a page
- **Tabs** — content in switchable tabs
- **Processed image** — an image from a post's folder, cropped or resized, with a caption

## What needs a developer

The site title, logo, colours and search settings are part of the site's code.
