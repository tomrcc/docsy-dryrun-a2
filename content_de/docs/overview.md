Diese Seite ist mit [Hugo](https://gohugo.io/) und dem Theme [Docsy](https://www.docsy.dev/) erstellt. In CloudCannon ist ihr Inhalt auf einige Sammlungen aufgeteilt, die in der Seitenleiste aufgeführt sind.

| Sammlung | Inhalt | Bearbeiten mit |
| --- | --- | --- |
| **Pages** | Die Startseite, „Über uns“, „Community“ und alle neuen Landingpages | Dem Visual Editor — Seiten bestehen aus Blöcken |
| **Docs** | Diese Dokumentation, eine Markdown-Datei pro Seite | Dem Visual Editor oder dem Content Editor |
| **Blog** | Neuigkeiten und Release-Beiträge | Dem Visual Editor oder dem Content Editor |
| **Site data** | Fußzeilentext und Community-Links | Dem Data Editor |

## Was im Code bleibt

Theme-Einstellungen — Farben, Logo, Suchmaschine und Seitentitel — befinden sich in `hugo.yaml` und im Ordner `assets/`. Bitten Sie einen Entwickler, sie zu ändern.
