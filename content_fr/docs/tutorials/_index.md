## Build a landing page

Landing pages — like the home and About pages — are made of blocks rather than
markdown.

1. Open the **Pages** collection and select **+ Add** → **Landing page**.
2. In the page sidebar, open **Content blocks** and add a **Cover** block.
3. Add a **Lead**, **Features** or **Section** block below it.
4. Click text in the preview to edit it in place, and drag blocks in the
   sidebar to reorder them.
5. To add the page to the top navigation, set **Menu → Main → Weight**.

## Change the footer

The footer's copyright text and links are shared by every page. Open **Site
data** → **Footer** to change the copyright, and **Site data** → **Links** to
change the icons in the footer and the lists on the Community page.
