Open the **Blog** collection and select **+ Add** → **Blog post**. The post
opens in the Content Editor, where you can write in markdown and add Docsy
components with the snippet button.

## Drafts

Turn on **Draft** in the sidebar to keep a post off the live site while you
work on it. Draft posts aren't built, so preview them in the Content Editor
rather than the Visual Editor.

## Dates and order

Posts are listed newest first, by **Date**.
