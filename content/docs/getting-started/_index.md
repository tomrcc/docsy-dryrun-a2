## Make your first edit

1. In CloudCannon, open the **Docs** collection and select this page.
2. The page opens in the Visual Editor. Click this paragraph and change a word.
3. Select **Save**. CloudCannon commits the change and rebuilds the site.

## Add a page

Open the **Docs** collection and select **+ Add**. Choose **Docs page** for a
single page, or **Docs section** for a new folder with its own landing page.
Give it a title, then write the content in the Content Editor.
